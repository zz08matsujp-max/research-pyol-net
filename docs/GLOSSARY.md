## 0. 使用方針

### 0.1 翻訳の品質基準（設計指示書 v1.1 §6.2）

- **誤訳ゼロ**を最優先（不自然さは許容、誤解は許容しない）
- **誇張禁止**: "groundbreaking", "revolutionary", "world-first", "novel" 等は使わない。原文の淡々さを保つ
- **術語の一貫性**: 本表を辞書として grep で検証
- **読みやすさは二の次**、まず正確さ
- v0.2 以降で継続的にブラッシュアップ

### 0.2 仏教術語の表記方針（v1.1 で保守化）

v0.1 では**英訳を第一表記とし、ローマ字や Skt. 由来語は基本的に出さない**。これは Toshi さん自身が仏教学者でないため、宗教学的精度を v0.1 で過度に主張することを避ける、誠実さ優先の判断である。

- 例: `mental afflictions` を使い、`bonnō` は文脈上どうしても必要な場合のみ補足
- v0.2 で駒澤大学・龍谷大学・仏教大学等の仏教学者と協議のうえ、ローマ字・Skt. 由来語の扱いを正式に確定する
- 構想記録 v1.4 の英訳冒頭または脚注に「Buddhist terminology in this translation is preliminary and will be refined in v0.2 in consultation with Buddhist scholars」を明記する

### 0.3 著者造語の表記方針

著者の造語（精密の経済、煩悩埋め込み、ExPFC など）には**必ず定義文を併記**する。初出時は1〜2文の操作的定義を添え、海外読者が「これは著者独自の概念である」と認識できるようにする。

## 3. 著者造語（**定義文の併記必須**）

| 日本語 | 英語 | 定義文（初出時に併記） |
|---|---|---|
| 精密の経済 | Economies of Precision | The economic principle of going narrow and deep on individual cases, in contrast to Economies of Scale, which goes wide and shallow. Per-judgment cost is high, but accuracy on individual vulnerability is preserved. |
| 規模の経済 | Economies of Scale | (既存術語、Adam Smith 由来。本文では "Big AI's optimization target" として言及) |
| やれるがやらない領域 | the "can-but-won't" domain | Domains that are technically tractable for Big AI but economically irrational to address, hence left structurally unattended. |
| 煩悩埋め込み | Bonnō Embedding | A learned mapping from text T to a 108-dimensional real-valued vector V, where each component represents how strongly the text stimulates the corresponding bonnō. |
| 煩悩埋め込み空間 | Bonnō Embedding Space | The 108-dimensional vector space induced by the Bonnō Embedding. |
| External Prefrontal Cortex (ExPFC) | External Prefrontal Cortex (ExPFC) | An external device that supplements the integrative judgment of a human prefrontal cortex when emotional arousal has impaired its function. The original term is in English. |
| 吟味モジュール | examination module / discernment module | The cognitive function of carefully evaluating the truthfulness of presented information. The five-senses metaphor identifies it as the function scammers deliberately bypass. |
| 五感メタファー | five-senses metaphor | A mapping in which the cognitive modules of the anti-scam system (visual / linguistic / behavioral / relational / temporal) are aligned with the human five senses. |
| 抑制構造 | suppression structure | A signature feature of scam text: alongside stimulating target bonnō (greed, loneliness), it actively suppresses bonnō related to caution (doubt, prudence). |
| 出典明示性 | source attribution / source transparency | The verifiability of the originator (company name, contact, registration number) of an advertisement or message. A legally grounded discriminating axis between legitimate ads and scams. |
| ミスマッチ思想 | mismatch thinking | The thesis that unexpected combinations across disciplines yield the strongest market differentiation. Originated in Toshi Matsuura's experience at Samsung SDS. |
| マインドシード哲学 | Mindseed philosophy | The author's overarching philosophy: "Protect Your Only Life" (PYOL), framing scam victimization not as financial loss but as a violation of the singular life itself. |
| Protect Your Only Life (PYOL) | Protect Your Only Life (PYOL) | (英語が原語、無翻訳で使用) |
| 1 to 1（深い）スケール | 1-to-1 (deep) scale | A scaling strategy of providing deep processing for each individual user, contrasted with 1-to-all (shallow) scaling. |
| インセンティブ非対称性 | incentive asymmetry | The structural condition in which SNS platforms profit from bonnō-stimulating content (engagement) and therefore lack the incentive to suppress it, even where technically capable. |
| 炎上経済学 | flame-war economics | An informal term for the SNS-platform incentive structure described above. |
| 煩悩感受性プロファイル | mental-affliction sensitivity profile | An individual's psychological tendency to be stimulated by particular afflictions. Introduced in v1.7 §16.4. Cannot be fully captured by labeling or behavioral observation alone — an incomplete-observation problem of inner information. |
| 共鳴 | resonance | The relationship between a text's affliction-stimulation profile and a user's affliction-sensitivity profile. Scam judgment is captured as resonance rather than text properties alone. |
| 3 項関係 | three-way relation | The structure of scam judgment as a function of (text, context, individual) rather than text alone. Introduced in v1.7 §16.4. |
| Level 0 自己反省的階層 | Level 0 self-reflective tier | A recursive tier in the research program's structure: the program recognizes its own observational limits as itself an object of study. The "research-program-observing-itself" structure introduced in v1.7 §16.4. Beyond the three tiers (methodological / strategic / applied) of §0.6. |
| 段階的個人化 | progressive personalization | A response strategy for the cold-start problem in user-profile learning: begin from an average profile and progressively refine based on behavior and self-report. |
| ユリシーズ契約 | Ulysses contract | A prior contract by which the user's "calm self" delegates intervention authority (e.g., the Tier C unconditional block of §16.4.2) to the ExPFC, to protect the user's "emotionally-overwhelmed self." Same structural logic as voluntary guardianship in Japan's adult-guardianship system. |
| 第三者通知 | third-party notification | A countermeasure to the SNS-mediated structural invalidation of physical third-party intervention (§1.2): the ExPFC automatically notifies pre-registered family or friends at high scam-score moments. |
| 段階的介入 | graded intervention | A tiered intervention design (Tier A informational / Tier B strong warning / Tier C unconditional block with cooling-off period) for the ExPFC. |
| 「過去の自己の手紙」UI | "letter from the past self" UI | A UI design pattern in which the ExPFC presents past self-reports as a letter, rather than third-party advice — a behavioral-economics Commitment Device adapted for psychological vulnerability. |
